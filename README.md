# Smp-sheet

Отдельный проект для электронного сопроводительного листа скорой медицинской помощи.

## Цель

Перенести бумажный сопроводительный лист из двух сторон А4 в электронную форму без изменений проекта `smp-duty`.

### Уже заложено

- данные пациента;
- место жительства и место оказания СМП;
- диагноз бригады;
- обстоятельства заболевания / несчастного случая;
- оказанная помощь;
- стационар и время доставки;
- состав бригады;
- АД и температура;
- глюкоза крови;
- LAMS;
- отдельная печатная логика как следующий этап.

## Запуск

```bash
npm install
npm run dev
```

## Следующий этап

Сверстать две печатные стороны А4 по фотографиям оригинального бланка и связать их с введёнными данными. Печать должна быть рассчитана на двусторонний режим.
